# Инструкция по исправлению проблем с договорами

## Проблемы, которые были решены:

1. **Не работает переход в детали договора**
2. **Не работает создание договоров**

## Что было сделано:

### 1. Исправление API-вызова получения договора
- **Файл:** `composable/useContracts.ts`
- **Проблема:** Функция `getContract` не добавляла загруженные данные в массив `contracts`
- **Решение:** Добавлено добавление договора в массив `contracts` после загрузки

### 2. Добавление детального логирования
- Добавлено логирование во всех ключевых функциях:
  - `getContracts` - загрузка списка договоров
  - `getContract` - загрузка конкретного договора
  - `createContract` - создание договора
  - `updateContract` - обновление договора
  - `addContractItem` - добавление поверхности к договору
  - `deleteContract` - удаление договора

### 3. Улучшение обработки ошибок
- Добавлено детальное логирование ошибок
- Улучшена валидация данных
- Добавлены защитные проверки

### 4. Добавление логирования в компоненты
- `pages/contracts/index.vue` - список договоров
- `pages/contracts/add.vue` - форма создания договора
- `components/ContractForm.vue` - компонент формы
- `pages/contracts/[id]/index.vue` - детали договора
- `components/ContractCard.vue` - карточка договора

## Как использовать для диагностики:

### 1. Проверка через консоль разработчика
1. Откройте консоль разработчика (F12)
2. Попробуйте перейти в детали договора
3. Попробуйте создать новый договор
4. Смотрите логи в консоли для диагностики проблем

### 2. Использование тестовой страницы
1. Откройте файл `test-contract-page.html` в браузере
2. Проверьте статус подключения к API
3. Используйте кнопки для тестирования функций:
   - "Получить список договоров"
   - "Создать договор"
   - "Получить договор" (введите ID)
   - "Добавить поверхность"
   - "Удалить договор"

### 3. Пошаговая диагностика

#### Проблема с переходом в договор:
1. Откройте список договоров
2. Нажмите на любой договор
3. Проверьте консоль:
   - Загружается ли договор?
   - Есть ли ошибки?
   - Найден ли договор в массиве?

#### Проблема с созданием договора:
1. Откройте форму создания договора
2. Попробуйте создать договор
3. Проверьте консоль:
   - Загружаются ли клиенты?
   - Есть ли валидация?
   - Успешно ли создается договор?

## Ключевые моменты для проверки:

### 1. API-подключение
- Проверьте, что сервер API доступен
- Проверьте URL в `nuxt.config.ts` (apiBase)

### 2. Данные клиентов
- Убедитесь, что в системе есть клиенты
- Проверьте, что клиенты загружаются в форме создания договора

### 3. Валидация данных
- Проверьте, что все обязательные поля заполнены
- Проверьте типы данных (ID должен быть числом)

### 4. Состояние загрузки
- Проверьте, что компоненты правильно обрабатывают состояние загрузки
- Убедитесь, что ошибки отображаются пользователю

## Возможные проблемы и решения:

### 1. Сервер недоступен
- Проверьте, что сервер API запущен
- Проверьте URL подключения

### 2. Нет клиентов
- Создайте хотя бы одного клиента в системе
- Проверьте, что клиенты загружаются

### 3. Ошибки валидации
- Проверьте формат данных
- Убедитесь, что все обязательные поля заполнены

### 4. Проблемы с маршрутизацией
- Проверьте, что маршруты правильно настроены
- Убедитесь, что параметры передаются корректно
